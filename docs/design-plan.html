COURTSIDE / PHASE 3 / HOMEPAGE

Website design plan.

A basketball community concept for new players, everyday players, and fans. The homepage introduces the brand, shares basketball fundamentals, and invites visitors to start a conversation.

04 / Interaction & responsive checks

  • Desktop: horizontal navigation, three cards, two-column story and contact.
  • Tablet: reduced spacing and flexible widths.
  • Mobile: wrapped navigation, stacked cards, story, contact, and form fields.
  • All fields are labeled. Name, email, topic, and message are required; malformed email and blank-only messages are rejected.
  • Preview output uses plain text. Editing a field hides the old preview. Keyboard focus moves to the completed preview.
  • Visible keyboard focus, skip link, descriptive heading hierarchy, and reduced-motion support.
Submission limitations: This homepage includes an interactive contact prototype, not a live inbox. Nothing is sent or stored. Actual delivery requires the group's chosen form service or backend.
