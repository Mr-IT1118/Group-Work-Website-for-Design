COURT PHANTOMS / PHASE 3 / WEBSITE DESIGN

Five pages.
One basketball identity.

The basketball website contains five independent visitor-facing pages. Each has its own HTML file, title, content, and active navigation state. This document is supplementary planning material.

01 / Site map and user journeys

PageFileUser journey
Homeindex.htmlBasketball hero → three page previews → promotional brochure → contact invitation
Aboutabout.htmlBrand introduction → purpose → values → visual identity
The Gamegame.htmlIntroduction → choose a skill → read cues → explore community
Communitycommunity.htmlWays to connect → game checklist → court etiquette → contact

All five pages link to one another through the shared header and footer. The homepage is the entry point; the other pages deepen the brand, learning, community, and contact experience. Home → The Game → Community → Contact is the primary visitor journey.

03 / Brand assets and hierarchy

Purple #7C3AEDLavender #C4A0FFInk #181221Paper #FAF8FF
  • Group-supplied Court Phantoms JJHT logo, consistently placed in the header and footer, with a larger version on About. Three additional group-supplied variants (monochrome, circular CP, and light-background) are shown below it. The CP emblem is the browser icon.
  • Headlines: Barlow Condensed, bold. Body and interface: DM Sans, with system fallbacks.
  • Headings use a clear H1 → H2 → H3 hierarchy; each page has one H1.
  • The existing optimized basketball hero JPEG is retained on the homepage, with alternative text and explicit image dimensions.
  • Rules, borders, numbered blocks, generous space, and the court-line motif tie the pages together.

04 / Interactions and responsive behavior

  • Homepage promotional brochure with full-size viewing and JPG download; About and footer brochure links. Five real page URLs, relative asset paths, active-page navigation, footer links, and skip links.
  • The Game: three skill buttons reveal corresponding content. Without JavaScript, all three sections remain readable.
  • Community: five local checklist items update a progress count and can be reset.
  • Contact: linked Instagram profile @courtphantomsjjht and original QR image; required fields, email validation, text-safe message preview, and expandable FAQ answers.
  • Mobile: wrapped navigation and stacked content; wider screens use columns.
  • Keyboard focus styles and reduced-motion support are retained.
  • CSS and JavaScript links include a release version to avoid reusing the old orange theme from browser cache.
